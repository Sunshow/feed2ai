# Chrome Web Store Listing

## English

**Name:** Feed2AI - Web Content Extractor for AI

**Short Description (132 chars max):**
Extract and clean web content with one click. Perfect for feeding articles, docs, and pages to ChatGPT, Claude, and other AI assistants.

**Detailed Description:**
Feed2AI helps you extract clean, readable content from any webpage and copy it to your clipboard - ready to paste into your favorite AI assistant.

**Features:**
• Visual Selection Mode - Click the extension icon to enter selection mode with element highlighting
• Smart Content Extraction - Uses Mozilla Readability to parse and clean messy HTML into readable text
• Multi-Select Support - Use Cmd/Ctrl+Click to select multiple elements
• Range Selection - Use Shift+Click to select a range of elements
• One-Click Copy - Extracted content is automatically copied to clipboard

**How to Use:**
1. Click the Feed2AI icon to enter selection mode
2. Click on any element to extract and copy immediately
3. Use Cmd/Ctrl+Click to add/remove elements from selection
4. Press Enter to copy all selected content
5. Paste into ChatGPT, Claude, or any AI assistant

## 中文

**名称:** Feed2AI - AI 内容提取助手

**简短描述 (132字符以内):**
一键提取网页干净内容，完美适配 ChatGPT、Claude 等 AI 助手。支持多选、范围选择，自动清理格式并复制到剪贴板。

**详细描述:**
Feed2AI 帮助你从任意网页提取干净、可读的内容，并自动复制到剪贴板，随时粘贴到你喜欢的 AI 助手中使用。

**功能特点:**
• 可视化选择模式 - 点击扩展图标进入选择模式，悬停高亮显示元素
• 智能内容提取 - 使用 Mozilla Readability 解析并清理杂乱的 HTML
• 多选支持 - 使用 Cmd/Ctrl+点击 选择多个元素
• 范围选择 - 使用 Shift+点击 选择一系列元素
• 一键复制 - 提取的内容自动复制到剪贴板

**使用方法:**
1. 点击 Feed2AI 图标进入选择模式
2. 点击任意元素立即提取并复制
3. 使用 Cmd/Ctrl+点击 添加/移除选中元素
4. 按 Enter 键复制所有选中内容
5. 粘贴到 ChatGPT、Claude 或任意 AI 助手
